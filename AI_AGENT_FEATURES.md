# AI Agent & Recent Fixes (Update Log)

## 1. New Feature: AI Agent Node 🤖
We have introduced a powerful AI Agent node that allows your WhatsApp bot to converse intelligently using state-of-the-art LLMs.

### Modes available
1. **Chat Completion (Standard)**
   - **Engines**: GPT-4o (OpenAI) or Gemini Pro 1.5 (Google).
   - **Best For**: General conversation, role-playing, translation.
   - **Context**: Automatically reads the last 10 messages of the chat history.

2. **OpenAI Assistant (Knowledge Base / RAG)**
   - **Engine**: OpenAI Assistants API.
   - **Best For**: Answering questions from specific documents (PDFs, Excel), Code execution, and complex behaviors.
   - **Features**: 
     - **Auto-Threading**: Automatically manages conversation threads for you.
     - **File Search**: Can read files uploaded to the OpenAI Dashboard.

## 2. Setup Instructions ⚙️

### A. Server Configuration
You must add your API keys to the `server/.env` file. Open the file and add:
```env
OPENAI_API_KEY=sk-proj-xxxxxxxxxxxxxxxxxxxxxxxx
GEMINI_API_KEY=AIzaSyxxxxxxxxxxxxxxxxxxxxxxxxx  # Optional, if using Google
```
**Note:** After saving the file, **restart your backend server** for changes to take effect.

### B. using "Knowledge Base" (RAG)
1. Go to [OpenAI Assistants](https://platform.openai.com/assistants).
2. Create a new Assistant (e.g. "Support Bot").
3. Enable **File Search** and upload your documents (PDFs, TXT, etc).
4. Copy the **Assistant ID** (starts with `asst_`).
5. In the Flow Builder, select the AI Agent Node.
6. Switch Mode to **OpenAI Assistant** and paste the ID.

## 3. How to Use in Flow 🌊

1. **Trigger**: Start with an **On Message** node (or Ask Question).
2. **AI Node**: Connect the "AI Agent" node immediately after.
   - Set the **Output Variable** (default: `ai_response`).
3. **Response**: Connect a **Text Message** node after the AI Agent.
   - In the text body, use the variable: `{{ai_response}}`.

**Example Flow:**
`[On Message] -> [AI Agent] -> [Text Message: {{ai_response}}]`
