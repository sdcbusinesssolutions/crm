# Fix Node Modules Corruption

This workflow addresses issues where the application fails to start due to `SyntaxError: Invalid or unexpected token` errors pointing to files within `node_modules` that contain garbage characters or binary noise.

## Symptoms
- `SyntaxError: Invalid or unexpected token` crashing the application.
- Error location points to a file deep inside `node_modules` (e.g., `googleapis`, `autoprefixer`).
- The file content, when viewed, resembles garbage or binary data (e.g., `$␦mmoLD`).

## Solution

The most reliable fix is to completely remove the corrupted dependencies and reinstall them.

### 1. Repair Server Dependencies
If the error occurs in the server logs:

```powershell
cd server
# Force remove the node_modules directory
Remove-Item -Recurse -Force node_modules
# Reinstall dependencies
npm install
```

### 2. Repair Client Dependencies
If the error occurs in the client build or dev server:

```powershell
cd client
# Force remove the node_modules directory
Remove-Item -Recurse -Force node_modules
# Reinstall dependencies
npm install
```

### 3. Verify the Fix
After reinstalling, verify the application starts correctly.

**For Server:**
```powershell
cd server
npm start
```

**For Client:**
```powershell
cd client
npm run build
```
