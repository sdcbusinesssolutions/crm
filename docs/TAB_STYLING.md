# Tab Styling Documentation (Contacts.tsx)

## Overview
This document details the specific styling rules applied to the navigation tabs in the Lead CRM (`Contacts.tsx`). The design follows a strict "Solid Brand Inactive / Distinct Color Active" pattern.

---

## 1. Global Concepts
- **Inactive State (Default)**: All tabs appear uniform, using the **Brand Color** (e.g., Orange) to match the primary "Create" buttons. This creates a cohesive, branded look for unselected items.
- **Active State (Selected)**: The selected tab switches to a unique, **Distinct Color** (e.g., Blue for Contacts, Green for Pipelines). This highlights the active context clearly.

---

## 2. Inactive Tab Styling
**Appearance**: Solid Brand Color background with White text.
**Class Utility**:
```tsx
const tabInactiveClass = 'bg-brand-600 text-white border border-brand-600 hover:bg-brand-700 hover:border-brand-700 transition-all shadow-md';
```
**Breakdown**:
- `bg-brand-600`: Solid brand background.
- `text-white`: High contrast text.
- `border-brand-600`: Matching border (appears seamless).
- `hover:bg-brand-700`: Darker shade on hover for interactivity.
- `shadow-md`: Subtle elevation.

## 4. Badge Styling (Counts)
The little number pill next to the text also changes based on state.

**Inactive Badge**:
- **Style**: White background with Brand text.
- **Goal**: High contrast against the solid Brand tab.
- **Code**: `bg-white text-brand-600 shadow-sm`

**Active Badge**:
- **Style**: Translucent White.
- **Goal**: Subtle integration with the solid Distinct tab color.
- **Code**: `bg-white/20 text-white`
