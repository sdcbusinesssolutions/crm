# Node.js Backend for WhatsApp Flow Builder

This is a simple Hello World REST API built with Express.

## Prerequisites
1. **Node.js** installed on your machine.

## Setup Instructions

1. **Navigate to the server directory:**
   ```bash
   cd server
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the Server:**
   ```bash
   npm start
   ```
   The server will run on `http://localhost:5000`.

## API Endpoints

- `GET /`: Returns a Hello World JSON response.
